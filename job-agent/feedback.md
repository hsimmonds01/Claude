# Steering

This is how you correct the agent. Every alert and every digest has a link
straight to this file — tap it, add a line, hit **Commit changes**. The next
run is sharper. Takes about fifteen seconds.

You do not need to be precise or polite. "no" is a valid line.

## Recent reactions

**Append-only.** Add new lines at the **bottom**. Only the most recent lines
are sent to the AI, so old reactions fade out by themselves — no need to
tidy this section, and no harm in contradicting yourself later. Later wins.

Date the line if you want, or don't. Both work.
