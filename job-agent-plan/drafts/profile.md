# What I'm looking for

This file tells the agent what a good job looks like *for me*.
It gets read fresh on every run, so any change takes effect within a few hours.

Edit it from the GitHub app: tap the file → pencil icon → change → **Commit changes**.
Nothing here is code. Write normally. Leave anything blank that doesn't matter to you.

> One thing to know: this file is what the AI uses to **judge** jobs.
> The literal words typed into the job sites to **find** jobs live in
> `config.yml` under `search_terms`. If you add a new job title here that
> you'd also want searched for, add it there too.

## What I actually want

Free text. This is the most useful section in the file — the tick-boxes above
can't capture "I want a team where I'm not the only person doing this" or
"I'm leaving because I have no one to learn from". Write it like you'd say it
to a friend. Ramble. The AI reads it properly.

>

## Things I'm working around

Anything that changes what's realistic rather than what's ideal — notice
period, visa, a course finishing in March, a house move, needing to start
before or after a certain date.
